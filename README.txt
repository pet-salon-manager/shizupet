しずペット - 静岡県ペットスーパーアプリ

このフォルダはそのままGitHub PagesなどのHTTPSホスティングに公開できます。

主な機能
- ペット登録
- 健康・体重・投薬・ワクチン・通院記録
- 静岡県内スポット検索（東部/中部/西部/伊豆）
- 店舗・施設の手動追加、検索、お気に入り、削除
- 防災チェックリスト
- 迷子対策メモ
- JSONバックアップ/復元
- 端末内保存（localStorage）
- PWA対応の土台

注意
- 初期の店舗・施設情報はサンプルです。実在店舗の最新情報は正式な店舗マスタを追加してください。
- 現在版は無料で動くよう、外部API・有料サービスを必須にしていません。
- クラウド同期、家族共有、ログイン、プッシュ通知を使う場合はSupabase等を後から接続できます。

GitHub Pages
1. GitHubで新しいリポジトリを作る
2. このフォルダ内の index.html / manifest.webmanifest / sw.js をアップロード
3. Settings → Pages
4. Deploy from a branch を選択
5. Branch: main / root を選択して Save
6. 数分後に表示される https://ユーザー名.github.io/リポジトリ名/ をSafariで開く
7. Safariの共有 → ホーム画面に追加
